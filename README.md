# 🐾 LeVetly Pet Clinic

A modern full-stack veterinary clinic management system built with React, Node.js, and MongoDB.

---

## ✨ Features

### 👨‍⚕️ Client Features
- Pet clinic landing page
- Veterinary services showcase
- Pet products shop
- Appointment booking
- User authentication
- Shopping cart
- FAQ section
- Responsive modern UI

### 🛠️ Admin Features
- Admin dashboard
- Manage products
- Add/Edit/Delete doctors
- Manage appointments
- Product management system
- Admin authentication

# 🚀 Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/yourusername/levetly-pet-clinic.git
```

---

## 2️⃣ Install Frontend Dependencies

```bash
cd FRONTEND
npm install
```

---

## 3️⃣ Install Backend Dependencies

```bash
cd BACKEND
npm install
```

---

# ▶️ Run Project

## Start Backend

```bash
npm start
```

## Start Frontend

```bash
npm start
```
